How the agents are measured

A one-person studio. The orchestrator is an overseer (Claude); execution belongs to the agents: Opus, Sonnet and Haiku runners that work from written orders, Gemini for research, heavy reading and images, Grok Bot for social pulse and red-teaming, and local models (Gemma, Qwen) for measurement and blind judging. The human has the last word.

The overseer writes no code: it measures, writes orders and asks for evidence. Every number on this page comes from a measurement and carries its stamp; everything that moves shows a number or a flow.

Methods we found

Each one is a working rule; where there is a number, its stamp stands next to it.

rule

The declaration rule (BEYAN)

The first line of every agent output: who · what (measurement, opinion or verdict) · confidence · basis · falsifier. A statement without a declaration does not count; the declaration gate checks this mechanically.

gate

Order + VERIFY gate

Every job is a single-file order; it ends with one command and one expected value. A job that does not pass the gate is not “done”. In the last hours orders ran; external rounds: .

memory

Claim → refutation

A diagnosis is written as a claim and falls by evidence; the default is to archive, not delete. Memory of fallen ideas: records (rejected by the human, permanent: ; fell by data: ).

measure

Report card (three questions)

For every tool: ① did it run · ② was it read · ③ did it change a decision. On the third question the canary is at : the count cannot be told apart from chance. Stated honestly: the measure does not discriminate yet.

life cycle

Retirement

A tool or agent that does not get a passing grade is retired, not deleted. Inventory: records; the service audit found schedulers, running, archive candidates. A method that yields nothing is retired too.

experiment

Permutation and ablation

The same task runs in three arms that differ by one change: model swapped (A) · gate skipped (B) · context pack skipped (C). All three arms passed the same gate with the same result; the difference stayed in cost. This is one measurement, not a generalisation.

Enlil stamps candidates and placebos shuffled and without context; position bias was measured. Before a new rule goes live it runs in shadow on the same inputs: n=, agreement , determinism . The shadow arm has not won yet: the copy baseline is , and the shadow arm is no better than copying ( ).

Self-test

Every tool tests itself: tools · passed · failed · no self-test · checks · s. A tool without a self-test is not wired into automatic runs.

loop

Evolution loop ()

Enkidu lists decaying rules and produces placebos → Enki writes at most candidates → Enlil stamps them blind → Enkidu keeps shadow statistics (Wilson interval, minimum detectable effect, episodes per arm). No new agent: what evolves is the rule set.

verdict

Falsifier

Every verdict is written with “what would make this fall”; the next round takes the previous verdict’s falsifier as input. This is how the system re-tests its own verdicts.

Retired

Permutation was retired

The “permutation” trial, in which agents were freed and shuffled, did not noticeably change any agent’s report card. It was retired on by human decision. That is the method: a method that yields nothing is retired too.
