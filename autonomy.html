How the agents are measured

A one-person studio; the Spark round and measurement gates stand at the center. Anu (Claude Fable) handles liaison and orchestration, Atlas (Gemini 4 Argon · 1M) execution and oversight, the session-isolated Context-Free Argon Web the external voice, Astra plus Grok Bot + Grok Assistant counter-theses and Red Team stress-testing, Enkidu and Enlil runs and blind judging, local models (Gemma, Qwen) measurement, Reaper auditing and falsification tests, and the 6-gate QAJAN hypotheses; Opus works on project sessions and architectural code, Sonnet on production code, Haiku on mechanical measurement. Spark exists for this: voices that cannot hear each other answer the same question, and evidence returns through the gate. The human has the last word. Only an anonymised mouth crop goes to cloud models; details on the Privacy page.

Atlas does not rely on guesswork: it measures, writes orders and demands evidence and falsifiers through the gates. Every number on this page comes from a measurement and carries its stamp; everything that moves shows a number or a flow.

Methods we found

Each one is a working rule; where there is a number, its stamp stands next to it.

rule

The declaration rule (BEYAN)

By rule, the first line of every agent output states: who · what (measurement, opinion or verdict) · confidence · basis · falsifier. Across task-bus records, 72.3% (422/584 · 19 Oct 2026 Reaper measurement; target threshold ≥80%) start with a declaration; the remaining lines are automated hook and status notices.

Retirement

A tool or agent that does not get a passing grade is retired, not deleted. Inventory: 420 records; the service audit found 208 schedulers, 43 running, 82 archive candidates. A method that yields nothing is retired too.

experiment

Permutation and ablation

The same task runs in three arms that differ by one change: model swapped (A) · gate skipped (B) · context pack skipped (C). All three arms passed the same gate with the same result; the difference stayed in cost. This is one measurement, not a generalisation.

Blind judge and shadow run

Enlil stamps candidates and placebos shuffled and without context; order bias was measured. Before a new rule goes live it runs in shadow on the same inputs: n=168, agreement 4%, determinism 100%. The shadow arm has not won yet: the copy baseline is 98.8%, and the shadow arm is no better than copying (K5′ −79).

source verification

Reaper: source verification

In a multi-voice Spark round every citation is tested one by one against Crossref, PubMed and DOI; a fabricated citation (including the light class) invalidates the answer mechanically. No voice is a benchmark by authority alone — the measure is what proves true; the ROTE (EZBER) tag separates answers to the brief’s specific question from generic literature summaries. 10 external voices scorecard: 394 citations → 360 verified · 9 unverified · 25 fabricated (Wave-1 322/356; S0 26/26, S3 38/38; S10 5 theses ELIMINATED; 4 local voices 18 severe fabrications ELIMINATED). Details: reaper-en.html#yontem · reaper-en.html#karne.

Other projects run by the same setup

The measurement loop does not run only for smile design. The same orchestrator, under the same rules (declaration, measurement, falsification test), also runs these.

project

Trading

An agent that executes purchases in the crypto market inside a pre-written plan. Inputs: market snapshot, liquidation map, outside voices and a hypothesis log. Orders are placed only within the plan and its limits; selling and risk decisions stay with a human.

project

Clinic management and data analysis

Measurement and recommendation reports produced by local agents from a dental clinic's management data (appointments, procedures, cost items). Patient data never leaves the machine.

project

Exam preparation program

A coaching agent for a student preparing for the university entrance exam: practice-test analysis, a schedule matched to the exam's subject weights, weekly progress measurement.

project

Personal assistant

An assistant that runs from the phone: daily tasks, reminders, source scanning. Only what matters reaches the human, in one line.

project

Spark: thesis and counter-thesis

We do this work together: Anu (Claude Fable) handles liaison and orchestration, Atlas (Gemini 4 Argon · 1M) execution and oversight; with Context-Free Argon Web, Opus, Sonnet and Haiku, blind voices write independent theses on the same question; Astra and Grok run counter-thesis and Red Team stress tests. Link: spark.html

project

Quantum-inspired permutation agents

An experimental setup that distributes the possible solution orderings of a problem to parallel agents and eliminates them by measurement; the surviving candidate is tested with a small pre-registered experiment.

project

Dynamic agents and outside voices

Shadow agents running day and night measure, catch contradictions and write handover notes; social pulse and red-team work sit in a separate agent. None of them rules; a claim stands or falls by measurement.

project

Website and AI visibility analysis

Measuring how a site is read by search engines (Google, Bing, Yandex) and AI assistants (ChatGPT, Claude, Gemini, Copilot, Perplexity): access for nine bots, structured data, clean-up of old addresses with 410, consistency of directory and business profiles. The measurement is run by an analysis agent and eight readers; seven of the readers run on a server in Turkey. Evidence: work done for an oral and dental health center in Sakarya.

What it gives: a numbered measurement and a list of fixes. What it does not give: a ranking or a visibility promise.

project

Skin and face correction in clinical photographs

Skin retouching, light and colour balancing in smile and face photographs. Patient identity is not processed: an anonymous crop and an external model are used. By regulation no before-and-after images are shown on the site; only the service description is here.

What it gives: a face image with balanced light and colour and retouched skin. What it does not give: a clinical outcome promise or before-and-after display.
